# ♻️ Smart Doorstep Recycling Collection Platform

An AI-powered digital platform designed to make recyclable waste collection easier, smarter, and more organized by connecting households, scrap collectors, and recycling units.

## 📌 Project Overview

The Smart Doorstep Recycling Collection Platform consists of two applications:

### 1. EcoPickup – Household Application
EcoPickup helps households manage recyclable waste conveniently through AI-based object identification and doorstep pickup services.

**Key Features:**
- AI-based identification of recyclable materials.
- Waste category identification.
- Doorstep pickup scheduling.
- Date and time slot selection.
- Address and location management.
- Pickup request tracking.
- Rewards and wallet management.
- Multilingual support.

### 2. Kabadiwala Connect – Recycling Ecosystem Application
Kabadiwala Connect connects scrap collectors, recyclers, and administrators through a digital platform.

**Key Features:**
- Separate login for collectors, recyclers, and administrators.
- Scrap batch management.
- Recycler discovery and connection.
- Scrap lot listing and requests.
- Transaction and delivery status tracking.
- Inventory management.
- Admin dashboard and analytics.
- Digital records and reports.

## 🔄 Project Workflow

1. Households identify recyclable waste using EcoPickup.
2. Users schedule a convenient doorstep pickup.
3. Scrap collectors collect and record the recyclable materials.
4. Collectors manage scrap batches through Kabadiwala Connect.
5. Recyclers browse available scrap materials and place requests.
6. Collectors and recyclers coordinate transactions and update delivery status.
